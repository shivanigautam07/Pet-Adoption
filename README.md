
# 🐾 Pet Adoption Website

A simple and responsive **Pet Adoption Website** built using **HTML and CSS**. This project provides a user-friendly interface where users can explore pets available for adoption.

## 🌟 Features

* 🐶 Browse pets available for adoption
* 🐱 Attractive and user-friendly interface
* 📱 Responsive design
* 🎨 Clean and modern UI
* 🐾 Dedicated pet adoption page

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/shivanigautam07/Pet-Adoption.git
```

2. Navigate to the project folder:

```bash
cd Pet-Adoption
```

3. Open `adoptpage.html` in your browser.
